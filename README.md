# TrainingCenter

Тестовое задание на ASP.NET Core (.NET 8): расчёт скидок и приём заявок на обратный звонок.

## Запуск

```sh
dotnet run --project src/TrainingCenter.Api --launch-profile http
```

Swagger: http://localhost:5080/swagger

## Расчёт скидок

`CartPricingService` выбирает максимальную скидку для каждого курса: 20% при старте менее чем через 5 дней или 30% для выпускника. Правила реализуют `IDiscountRule` и подключаются через DI.

Пять дней считаются как 120 часов. Начавшиеся курсы и старт ровно через пять дней не дают скидку горящей группы. Цена каждого курса после скидки округляется до копеек.

## Заявки

`POST /api/leads`

```json
{
  "name": "Иван",
  "phone": "+7 999 123-45-67",
  "email": "ivan@example.com",
  "clientType": "Individual"
}
```

Тип клиента: `Individual` или `Corporate`. Некорректные данные возвращают 400.

Основной почтовый сервис имитирует сбой, после чего заявка передаётся резервному. Адреса заданы в `appsettings.json`. Отправка писем имитируется. После вызова резервного сервиса API возвращает 200 OK.

## Тесты

```sh
dotnet test TrainingCenter.sln
```

Проверяются скидки, границы дат, подключение дополнительных правил и резервная отправка для обоих типов клиента.
